# i-tasks

Dein persönlicher Begleiter für Android. Version 0.904 · Beta · Android ab 8.0.

[Downloadseite und Installationshinweise](https://willmann153-sys.github.io/i-tasks/) · [Aktuelle APK herunterladen](https://github.com/willmann153-sys/i-tasks/releases/latest/download/i-tasks.apk)

i-tasks verbindet neun Module: Aufgaben, Kalender, News, Notizen, Listen, Logbuch, Tagebuch, Login und i-assistent. Die Downloadseite beschreibt die Funktionen und zeigt acht App-Ansichten mit fiktiven Demodaten. Ihre Adresse bleibt unverändert, damit bereits verteilte QR-Codes weiter funktionieren.

## Installation und Updates

Lade `i-tasks.apk` herunter und öffne sie auf deinem Android-Gerät. Erstelle vor einer Aktualisierung eine Datensicherung in der App. Installiere über die vorhandene App. Die Prüfsumme steht in `SHA256SUMS.txt`.

Ab 0.904: **Mehr → Auf Updates prüfen**. Die App prüft auf Wunsch den öffentlichen Google-Drive-Updateordner anhand der Versionsnummern in den APK-Dateinamen. Bei einer neueren Version bietet sie den Download an und prüft vor der Installation APK-Version, App-Kennung und digitale Signatur. Android bestätigt die Installation; eine automatische Hintergrundinstallation findet nicht statt.

Für die Veröffentlichung auf GitHub heißt das APK-Asset versionsunabhängig `i-tasks.apk`. Im Drive-Updateordner behalten die APKs ihre Versionsnummer im Namen, etwa `i-tasks-0.904.apk`.
