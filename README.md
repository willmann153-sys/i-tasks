# i-tasks

Dein persönlicher Begleiter für Android. Version 0.901 · Beta · Android ab 8.0.

[APK und Installationshinweise](https://github.com/willmann153-sys/i-tasks/releases/tag/v0.901)

i-tasks verbindet neun Module: Aufgaben, Kalender, News, Notizen, Listen, Logbuch, Tagebuch, Login und i-assistent. Die Downloadseite beschreibt die Funktionen ausführlich und zeigt acht App-Ansichten mit fiktiven Demodaten.

## Installation

Lade `i-tasks-0.901.apk` aus dem Release herunter und öffne sie auf deinem Android-Gerät. Erstelle vor einer Aktualisierung eine Datensicherung in der App. Die Prüfsumme steht in `SHA256SUMS.txt`.
